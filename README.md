### Research Interests

- **Cloud-Native & Service Mesh Security:** Decentralized, service-level DDoS detection, pod-level attribution, and conflict-free policy reconciliation in **Kubernetes** and **Istio** (`EnvoyFilter` / `AuthorizationPolicy`).
- **Continuous Regulatory Compliance & Assurance:** Automated **7-Level Goal Structuring Notation (GSN)** Security Assurance Case (SAC) instantiation, **Labeled Property Graph (LPG)** architecture modeling, and **MAPE-K** runtime self-adaptation under **NIST SP 800-53**.
- **Applied Machine Learning for Cybersecurity:** Low-latency, calibrated ensemble models (`RandomForest`, `HistGradientBoosting`) for real-time telemetry classification and anomaly detection.
- **Data Security, Privacy & Wireless Networking:** Resilient distributed architectures and secure communication protocols.
